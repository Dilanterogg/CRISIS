# SimuCrisis — Simulador de Abastecimiento y Economía Familiar

**Desafío Final — Programación Web I**

## Descripción

Página web interactiva que permite simular y visualizar problemas reales relacionados con el abastecimiento de carburantes, precios de alimentos, transporte, compras familiares, rumores de escasez y pérdida del poder adquisitivo.

Desarrollada con propósitos exclusivamente **educativos**, usando modelos matemáticos sencillos para comprender el impacto económico en familias y comunidades.

---

## Tecnologías utilizadas

- **HTML5** — Estructura semántica (`header`, `nav`, `main`, `section`, `article`, `footer`)
- **CSS3** — Estilos externos, diseño responsivo con media queries, degradés, animaciones
- **JavaScript** — Cálculos, validaciones, manipulación del DOM
- **DOM API** — `getElementById`, `querySelector`, `innerHTML`, `addEventListener`
- **Git / GitHub** — Control de versiones
- **GitHub Pages** — Publicación

---

## Escenarios incluidos

| Escenario | Descripción |
|-----------|-------------|
| A — Carburante | Calcula cuántos días durará la reserva de combustible |
| B — Precios | Simula el impacto del aumento de precios en la canasta básica |
| C — Transporte | Estima el costo adicional por desvíos o bloqueos |
| D — Compras Familiares | Verifica si el presupuesto alcanza para la compra |
| E — Rumor de Escasez | Modela cómo los rumores generan compras de pánico |
| F — Poder Adquisitivo | Calcula la pérdida de poder de compra con el mismo salario |
